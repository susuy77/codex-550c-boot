# 兼容性与验证边界

已经在 Windows 上的 Store 包 26.930.3930.0、内部应用版本 26.930.31730 上验证内部动画、撤销、重新启用、候选启动和版本快照切换。
这不是所有版本的支持声明。公开整理版本的首次安装验证结果由维护者在 CHANGELOG.md 记录。

支持的结构：packed ASAR，webview/index.html，单个 root 元素，模块入口，显式 script-src self CSP，ChatGPT.exe 中单个 resources/app.asar SHA256 校验记录。
检查不满足时拒绝继续。支持启动页面内容与资产文件名变化；不自动适配启动入口改名、复杂 CSP 分支、加密资源或多重校验记录。

故障保护有 28 秒计时器和 30 秒 CSS 隐藏；尚未全面故障注入。动画退出不等待全部网络服务准备好，窗口创建前的空白也无法由 HTML 遮罩覆盖。
不同屏幕缩放、低性能机器和所有附属窗口路由尚未全面测试；avatar-overlay 已显式跳过。

修改副本签名失效的影响仍存在。已观察到后台网络连接失败，根因未确认；不能从动画成功推断登录、聊天、工具和插件全部正常。

版本回退保留当前配置可能遇到数据格式不兼容，可用包含配置快照的回退入口；新数据保存在快照里，不自动合并。首次安装没有上一版本可回退，但可撤销动画或继续使用官方原版。

历史快照随升级增长，不自动删除。维护命令需 Node.js 22+；不要把本机 .local 数据用于公开发布。
