# v0.1.0 验证记录

公开源码整理版于 2026-10-06 在 Windows 上实际验证，Node.js 24.19.0。

- 从干净数据目录运行安装脚本，读取官方 Store 包 26.930.3930.0，内部版本 26.930.31730。
- 候选副本采用临时独立配置启动，日志记录动画 START 和 END，启动检查通过后切换。
- 撤销动画后，可执行文件 Authenticode 状态恢复 Valid；重新启用后归档与程序内嵌哈希一致。
- 官方安装程序的签名仍为 Valid。
- 源码回归测试验证新版页面/资产/CSP 保留、结构不兼容拒绝、ASAR 重建、灵活 JSON 校验记录、精确撤销、升级中断恢复。
- PowerShell 解析检查及发布白名单审计通过；发布物不含应用二进制、资源归档、账户配置及本机日志。

此前本机适配版验证了升级快照切换和含配置回退；公开整理版未覆盖所有真实未来版本。CI 会验证 Node.js 22/24 与 Windows/Linux 的源码测试；Linux 不运行 Windows 安装或恢复脚本。

未全面验证：登录、聊天、插件、所有附属窗口、全部缩放与硬件组合、故障保护的所有故障情形。修改副本会使数字签名失效；请参阅 COMPATIBILITY.md。
