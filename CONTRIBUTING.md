# Contributing

Run `npm run build`, `npm test`, and `npm run verify` before submitting a patch. Windows PowerShell scripts must remain compatible with Windows PowerShell 5.1. Preserve strict compatibility refusal and original-installation isolation.

Include the Codex package/internal version and redacted error description when reporting compatibility problems. Do not attach executable files, ASAR archives, profiles, account tokens or full application logs. New versions require local validation; fixture-only tests must be identified as such.

Keep upstream credits and licenses. By submitting changes, you agree to license your contribution under this project's MIT license.
